# jameselkins/homebrew-tap

Homebrew formulas for [jameselkins](https://github.com/jameselkins)'s macOS tools.

## Install

```sh
brew tap jameselkins/tap
brew install remote-image-paste
```

## Formulas

| Formula | Description |
| --- | --- |
| [remote-image-paste](https://github.com/jameselkins/remote-image-paste) | Paste clipboard images into remote OpenCode sessions over SSH from macOS Ghostty |

Formulas are sourced from their upstream release tags. To update one, bump the
`version` and `url` in `Formula/` and run `brew test` before pushing.
